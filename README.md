# Nord Mousepad Theme ❄️

A clean, minimal **dark-mode mousepad design** inspired by the Nord color palette.  
Built for low-light setups and people who hate visual noise.

## Preview
![Nord Mousepad Preview](preview.png)

## Features
- Nord-inspired dark color scheme
- Minimal, distraction-free design
- Optimized for dark setups
- High-resolution export suitable for print

## Files
- `nord-mousepad.png` — final mousepad design  
- `preview.png` — preview image for GitHub
- `nord-mousepad.xml` — Mousepad (GtkSourceView) Nord theme
